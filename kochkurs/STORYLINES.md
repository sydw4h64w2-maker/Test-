# Kochkurs-Serie – Storylines (Folge 1: Pfannkuchen)

## A – „Mias Küche" (Empfehlung)
Kochshow mit Ritual: Mia (ca. 6) steht auf einem Hocker, Mama/Opa hilft beim Herd. Jede Folge gleicher Ablauf, anderes Rezept.
- Erste 2 s: Mia knallt das Rezeptbuch auf die Arbeitsfläche, schaut in die Kamera: „Heute: Pfannkuchen!"
- Beats: Rezept-Ansage → Zutaten (Draufsicht) → Rühren, Mehl staubt → Wenden mit Erwachsenem → Probieren, Reaktion → Endkarte „Morgen: …"
- Look: warme Holzküche, Draufsicht + Gesichts-Close-ups, große runde Schrift für Zutaten
- Ton: fröhliche Ukulele, Brutzeln, Schneebesen, Kinderlachen

## B – „Baby-Chef"
Komödie: Ein Baby mit Kochmütze „leitet" die Küche, ein Erwachsener führt aus. Ergebnis zuerst, dann rückwärts.
- Erste 2 s: fertiger Pfannkuchenturm, Sirup läuft – Schnitt auf das Baby, das streng darauf zeigt.
- Beats: Ergebnis → „Wie kam's dazu?" → Baby zeigt auf Zutaten → Missgeschick (Mehlwolke) → Rettung → Baby nickt zufrieden
- Look: helle Küche, Sitcom-Frontalkamera, Zutaten-Labels wie Speisekarten-Schrift
- Ton: verspielte Pizzicato-Streicher, Baby-Brabbeln als Kommentar

## C – „Eine Einstellung" (die mutige)
Eine einzige Draufsicht-Einstellung ohne Schnitt: nur Kinderhände, ASMR, das Rezept erscheint als Schrift auf der Arbeitsfläche. Erst ganz am Ende zeigt sich das Gesicht.
- Erste 2 s: kleine Hände schlagen ein Ei auf, Schrift „2 Eier" erscheint daneben.
- Beats: Zutaten nacheinander → Teig → Pfanne → Wenden → Teller → Kamera hebt sich, Mädchen grinst
- Look: Marmor/Holz von oben, minimalistische Typografie
- Ton: kein Musikbett, nur echte Küchengeräusche, leise Klavierschluss
